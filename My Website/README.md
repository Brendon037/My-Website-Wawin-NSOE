# Wawin National School of Excellence Website

This project contains a static multi-page website for Wawin National School of Excellence in Lae, Papua New Guinea.

## Pages

- Home
- About
- Programs
- News
- Contact

## Features

- Bright yellow school branding and strong black background contrast
- Hero section with school background image and welcoming introductory content
- About page with mission, vision, values, achievements, and contact information
- Programs page highlighting STEM, English, and ICT
- News page for recent updates and events
- Contact page with inquiry form and embedded live map
- Responsive layout for desktop and mobile devices

## Project Files

- `index.html` — homepage
- `about.html` — school overview
- `programs.html` — academic offerings
- `news.html` — school news and updates
- `contact.html` — contact information and inquiry form
- `style.css` — shared styling for all pages
- `images/` — school images used as backgrounds and visual highlights across the site

## Local Preview

You can view the site locally by running a simple web server from the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
